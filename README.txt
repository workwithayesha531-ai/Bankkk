# Academic Banking UI Demo

This package is a front-end academic demo, not a real bank website. It is deliberately labelled as an independent demo, uses generic branding, and has no username/password login form or banking-data collection.

## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — demo interactions

## Deploy
Upload these three files to the root of your GitHub Pages repository. Keep the filenames exactly as shown. The Font Awesome and GSAP assets load from CDNs.

## Important
This can reduce impersonation signals, but it cannot guarantee immediate removal of Chrome's warning. Check Google Safe Browsing Transparency Report and follow Google's review process after the live site has been corrected. Do not use the real bank's logo or imply affiliation.
